# Full-Stack Week 1

A responsive, mobile-first frontend project built with semantic HTML, modern CSS, and a small amount of JavaScript for interaction.

## Overview

This project focuses on clean structure, responsive layout, and accessible UI patterns. It includes:

- Semantic HTML landmarks and content sections
- Mobile-first responsive styling with CSS Grid and Flexbox
- A lightweight JavaScript interaction for theme accent toggling
- Smooth reveal animations for page sections

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Fonts: Plus Jakarta Sans and Space Grotesk

## Features

- Responsive header and navigation
- Hero section with a visual device mockup
- Vision, toolkit, roadmap, and demo sections
- Accessible button and link structure
- Accent mood toggle to demonstrate basic interactivity
- Scroll reveal animations using `IntersectionObserver`

## Files

- `index.html` - main page structure and content
- `styles.css` - visual design, layout, and responsive behavior
- `script.js` - toggle interaction and reveal animation behavior

## How to Run

1. Open `index.html` in a browser.
2. Resize the window to see the layout adapt across screen sizes.
3. Click `Toggle accent mood` to see the JavaScript interaction.

## Notes

- The project is intentionally framework-free to keep the focus on core frontend fundamentals.
- The design is optimized for clarity on mobile first, then expands cleanly on larger screens.
